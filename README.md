# ShinClipboard（シン・クリップボード）

Windows / macOS 向けの、クリップボード履歴・定型文・連続貼り付け管理アプリです。

## 主な機能

- テキストと画像のクリップボード履歴を自動保存（重複は最新位置へ移動）
- 定型文をグループ分けし、個別のグローバルショートカットから貼り付け
- 設定・編集画面と、履歴／定型文だけを表示するコンパクトな呼び出し画面を分離
- Ctrlキー2回（または任意に設定したショートカット）で、どのアプリからでも呼び出し画面を表示
- 呼び出し画面の `1〜0、a〜z`、シングルクリック、Enterで元のアプリへ即時貼り付け
- 呼び出し画面は `Tab` で履歴⇔定型文を切替、`←` / `→` で定型文グループを切替
- 呼び出し画面の履歴に画像のサムネイルを表示
- `#RRGGBB` などの色コードをコピーすると、履歴にその色の見本を表示
- よく使う色と画像をグループ分けして登録し、呼び出し画面やショートカットから貼り付け
- 呼び出し画面の履歴・色・画像を他のアプリへドラッグ＆ドロップ（画像はPNGファイル、テキストは文字列として渡す）
- 範囲・ウィンドウ・モニタ単位のスクリーンショット撮影（マルチモニタと混在DPIに対応）
- 注釈エディタで矢印・矩形・楕円・ペン・文字・番号バッジ・マーカー・ぼかし・モザイク・切り抜きを追加
- 描いた図形は後から選択・移動・削除でき、Ctrl+Z（macOSでは Cmd+Z）で取り消せる
- 編集結果はクリップボード・ファイル保存・履歴・ドラッグ＆ドロップの4通りで取り出せる
- FIFO / LIFOモードで、コピー順または逆順に連続貼り付け
- ストックの追加・編集・削除・貼り付け取り消し・全件連結
- 履歴の編集・複数選択連結・改行ごとの展開
- 定型文とグループの検索・編集・並び替え・CSV入出力（Clibor形式対応）
- 各行挿入、前後挿入、連番、正規表現、大小文字変換などのテキスト整形
- 整形ルールのショートカットとコピー時の自動整形
- クリップボード監視の一時停止
- 全データのZIPバックアップと復元
- OSログイン時の自動起動、常に手前、フォントサイズ、配色設定
- 定型文・色・画像・整形ルールを1つのZIP（引き継ぎパッケージ）にまとめて他の端末へ移し、置き換えまたは追加（マージ）で取り込み
- OS非依存のUTF-8 `config.json` を書き出し・読み込み
- 履歴はローカルの `history.json` に分離し、設定移管時に漏らさない
- タスクトレイ（macOSはメニューバー）常駐
- 多重起動防止（再実行時は既存の呼び出し画面を表示）

`primary` はWindowsではCtrl、macOSではCommandへ自動変換されます。

## ダウンロード

Windows版は[リリースページ](https://github.com/Yu-Rin-Chi2/ShinClipboard/releases/latest)から `ShinClipboard.exe` をダウンロードしてください。Pythonのインストールもインストーラーも管理者権限も不要で、任意の場所に置いてダブルクリックするだけで動きます。

初回起動時にWindows SmartScreenの警告が出ます。回避手順は「[配布版の実行について](#配布版の実行について)」を参照してください。

macOS版は同じリリースページの `ShinClipboard-macos.zip` です。展開して `ShinClipboard.app` を「アプリケーション」へ入れてください。ただし公証（notarization）を通していないため、ダウンロードしたままでは Gatekeeper に止められます。`xattr -dr com.apple.quarantine /Applications/ShinClipboard.app` を実行してから開いてください。気になる場合は下記の手順でソースから起動できます。

初回起動時にアクセシビリティの許可を求められます。詳しくは「[macOSの許可](#macosの許可)」を参照してください。

## ソースから起動

Python 3.10以降を利用します。

Windows:

```powershell
py -3.11 -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
.venv\Scripts\python main.py
```

macOS:

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python main.py
```

配布版のmacOSアプリは `ShinClipboard.app` です。ビルド方法は「テストと実行ファイル」を参照してください。

### macOSの許可

macOSは2つの許可を求めます。どちらも設定タブの「macOS の許可」で状態を確認でき、その場で許可画面を開けます。

| 許可 | これがないと使えない機能 |
|------|--------------------------|
| アクセシビリティ | Ctrlキー2回などのグローバルショートカット、選んだ内容の自動貼り付け |
| 画面収録 | スクリーンショットの撮影 |

許可の対象は起動したものです。`ShinClipboard.app` から起動したならアプリ本体、`python main.py` で起動したならターミナル（またはVS Codeなど）を許可してください。

アクセシビリティが未許可のまま起動すると、macOSはショートカット用のイベントタップを作った直後に無効化します。この状態ではCtrlキー2回を含むショートカットが一切反応しません。アプリは許可の状態を数秒ごとに見ているので、あとから許可すれば再起動しなくてもショートカットが有効になります。画面収録は許可のあとにアプリを再起動してください。

一覧でスイッチがONになっているのに設定タブが「未許可」のままなら、その登録は古い署名のものです。macOSは許可をそのときの署名に結びつけて覚えるため、署名が変わったビルドではONに見えても適用されません。スイッチを切り替えても記録は書き直されないので、「−」で削除してから「+」で追加し直してください。コマンドなら `tccutil reset Accessibility com.shinclipboard.app` で登録を消し、アプリを起動し直すと許可を求め直します。

### macOSでの制限

ドラッグ＆ドロップはtkinterdnd2に同梱されたtkdndを使います。tkinterdnd2はOS・CPU・Tclメジャーバージョンの組み合わせごとに
バイナリを持っていますが、Intel MacのTcl 9向けだけが存在しません。この組み合わせではドラッグ＆ドロップだけが無効になり、
ステータス欄に理由が出ます。他の機能には影響しません。Apple Silicon、またはTcl 8.6のPython（python.org版など）では使えます。

## 使い方

### 画面の構成

アプリには2つの画面があります。

| 画面 | 役割 | 開き方 |
|------|------|--------|
| 呼び出し画面 | 履歴・定型文・色・画像を一覧し、選んだ項目を元のアプリへ貼り付ける小さな窓 | Ctrlキー2回、または常駐アイコンの「貼り付け候補を開く」 |
| 設定・編集画面 | 履歴の整理、定型文・色・画像の登録、FIFO、整形ルール、各種設定 | 常駐アイコンの「設定・編集を開く」 |

起動すると常駐アイコンになります。Windowsではタスクトレイ、macOSではメニューバーです。ウィンドウを閉じても終了はせず、
常駐アイコンの「終了」で終わります。そのメニューからは、両画面の表示のほか、スクリーンショット撮影、クリップボード画像の編集、
FIFO / LIFO切替、監視の一時停止が行えます。

### 履歴を貼り付ける

1. いつもどおり `Ctrl+C` でテキストや画像をコピーします。自動的に履歴へ保存されます（同じ内容は最新位置へ移動）。
2. 貼り付けたいアプリの入力欄にカーソルを置き、Ctrlキーを素早く2回押します。
3. 呼び出し画面で貼り付けたい項目を選びます。行頭のキー（`1〜0`、`a〜z`）を押すのが最速です。
4. 選んだ内容が呼び出し画面を開く前のアプリへ貼り付けられ、画面は自動で閉じます。

呼び出し画面のキー操作は次のとおりです。

| キー | 動作 |
|------|------|
| `1〜0`、`a〜z` | 行頭に表示されたキーの項目を即時貼り付け |
| `↑` / `↓` + `Enter` | 選んで貼り付け |
| シングルクリック | クリックした項目を貼り付け |
| `Tab` / `Shift+Tab` | 履歴 → 定型文 → 色 → 画像 のタブを巡回 |
| `←` / `→`（`Ctrl+←` / `Ctrl+→`も可） | 定型文・色・画像のグループを切替 |
| `Ctrl+E` | 選択中の画像を注釈エディタで開く |
| 右クリック | 貼り付け、画像の編集、履歴の色・画像をライブラリへ登録 |
| ドラッグ | 項目を他のアプリへドロップ（画像はPNGファイル、テキストは文字列） |
| `Esc` | 閉じる |

履歴の検索や複数選択は設定・編集画面の「履歴」タブで行います。ここでは選択項目の削除・全削除、テキストの編集、改行ごとの分割（「改行ごとに展開」）、複数項目の連結、画像の編集ができます。右クリックメニューからは、コピーした色コードを「色」タブへ、画像を「画像」タブへ登録できます。

`#f00`、`#075dcc`、`#00000080` のような `#` で始まる色コードをコピーすると、呼び出し画面の履歴にはその色の見本が並び、設定・編集画面では `[色]` と表示されます。検索欄に「色」と入れると色コードだけを絞り込めます。`#` のない `075dcc` や `0x075dcc` は普通の文字列として扱います。

### 定型文を登録して貼り付ける

1. 設定・編集画面の「定型文」タブを開きます。
2. 左の「グループ」で「追加」を押し、グループ名を入力します（既定で「サンプル」グループがあります）。
3. 右の「追加」で定型文を登録します。名前・メモ・内容のほか、任意でショートカット（例: `primary+alt+1`）を設定できます。
4. 貼り付けるときは、呼び出し画面で `Tab` を押して定型文タブに切り替え、`←` / `→` でグループを選び、行頭のキーを押します。
   ショートカットを設定した定型文は、呼び出し画面を開かずにそのキーだけで貼り付けられます。

定型文とグループは `↑` / `↓` ボタンで並び替えられ、「定型文検索」欄で絞り込めます。CSVでの入出力は後述の「バックアップとCSV」を参照してください。

### 色と画像を登録して貼り付ける

定型文と同じ要領で、「色」タブと「画像」タブにもグループを作って登録します。

- 色: 名前と値（`#RRGGBB` または `#RRGGBBAA`）を登録します。「選ぶ…」でカラーピッカーから拾えます。貼り付けると登録した表記がそのまま文字列として入ります
- 画像: 名前と画像を登録します。画像は「ファイルを選ぶ…」「クリップボードの画像」のほか、履歴タブの右クリック「画像に登録...」からも取り込めます。貼り付けると画像としてクリップボードに入り、そのまま貼り付け先へ渡ります
- 画像ファイルをエクスプローラー（Finder）から「画像」タブの表、または呼び出し画面の「画像」タブへドロップすると、ファイル名を名前にしてまとめて登録されます。名前やショートカットは後から「編集」で変えられます

呼び出し画面では `Tab` で「色」「画像」タブへ切り替え、`←` / `→` でグループを選び、行頭のキーを押します。どちらもショートカット（例: `primary+alt+1`）を設定でき、設定した項目は呼び出し画面を開かずに貼り付けられます。

登録した画像は保存先の `library/` に置かれ、設定JSONにはそのファイル名だけが入ります。別端末へ持っていくときは「全バックアップ」を使ってください（設定の書き出しだけでは画像ファイルは移りません）。

### 連続貼り付け（FIFO / LIFO）

複数箇所からコピーした内容を、順番に貼り付けていく機能です。

1. `Ctrl+Shift+F`（FIFO）または `Ctrl+Shift+L`（LIFO）を押すか、「FIFO」タブの「FIFO開始」「LIFO開始」を押します。
2. 貼り付けたい内容を順にコピーします。コピーするたびにストックへ溜まります。
3. 貼り付け先で通常どおり `Ctrl+V` を押します。押すたびに次の1件が貼り付けられます。
   FIFOはコピーした順、LIFOは最後にコピーしたものから貼り付けます。
4. 終わったら同じショートカットをもう一度押すか、「停止」を押します。

間違えて貼り付けたときは `Ctrl+Shift+Z` で直前の1件をストックへ戻せます。「FIFO」タブではストックの内容を直接追加・編集・削除でき、「全件を改行で連結」で1つにまとめられます。

### クリップボード監視の一時停止

パスワードなど履歴に残したくないものをコピーするときは、`Ctrl+Shift+M` か常駐アイコンの「クリップボード監視 切替」で監視を止めます。停止中はコピーしても履歴に保存されません。もう一度押すと再開します。

### 設定・編集画面のタブ

| タブ | 内容 |
|------|------|
| 履歴 | 検索、削除、編集、連結、改行ごとの展開、画像の編集、色・画像のライブラリへの登録 |
| 定型文 | グループと定型文の追加・編集・削除・並び替え |
| 色 | グループと色の追加・編集・削除・並び替え。カラーピッカーで値を選べる |
| 画像 | グループと画像の追加・編集・削除・並び替え。ファイル・クリップボードから取り込む |
| FIFO | ストックモードの開始・停止とストック内容の編集 |
| 整形 | テキスト整形ルールの追加・編集と、選択中の履歴への適用 |
| 設定 | ショートカット、履歴保持件数、動作・表示、スクリーンショット、他の端末への引き継ぎ、CSV・バックアップ |

「設定」タブの主な項目は次のとおりです。変更後は「設定を保存」を押してください。

- 画面表示ショートカット: Ctrlキー2回に加えて使うキー（例 `primary+shift+space`）。既定は空欄
- 履歴保持件数: 既定は1000件
- 選択時に自動貼り付け: オフにすると、呼び出し画面で選んだ項目はクリップボードへコピーするだけになります
- 履歴を終了後も保存 / 終了時に履歴を削除
- 常に手前へ表示、最小化状態で起動、OSログイン時に起動
- Ctrlキー2回で画面表示: オフにすると画面表示ショートカットのみで開きます
- フォントサイズ、配色: 既定の `system` は macOS のライト／ダークモードに追従します（切り替えにもその場で追従）。`blue` `dark` `green` は固定の配色です。Windows では `system` は `blue` と同じです

### グローバルショートカット一覧

`primary` はWindowsではCtrl、macOSではCommandです。

| 動作 | 既定 | 変更 |
|------|------|------|
| 呼び出し画面を表示 | Ctrlキー2回 | 設定タブ（追加キーも指定可） |
| FIFO切替 | `primary+shift+f` | 設定タブ |
| LIFO切替 | `primary+shift+l` | 設定タブ |
| 監視切替 | `primary+shift+m` | 設定タブ |
| 貼り付けを1つ戻す | `primary+shift+z` | 固定 |
| スクリーンショット撮影 | `primary+alt+s` | 設定タブ（空欄で無効） |
| ディレイ撮影（既定3秒後） | `primary+alt+d` | 設定タブ（秒数も変更可、空欄で無効） |
| 定型文の貼り付け | なし | 定型文ごとに設定 |
| 色・画像の貼り付け | なし | 色・画像ごとに設定 |
| 整形ルールの適用 | なし | ルールごとに設定 |

ショートカットは `primary+alt+1` のように `+` でつなげて指定します。修飾キーは `primary`、`ctrl`、`cmd`、`alt`、`shift`、キーは英数字のほか `space`、`enter`、`tab`、`f1〜f12` などが使えます。修飾キーを含む2キー以上で指定してください。

## スクリーンショットと注釈

`Ctrl+Alt+S`（macOSでは `Cmd+Option+S`。いずれも既定）で画面が固まり、全モニタを覆う選択画面になります。Windows標準の `Win+Shift+S`、macOS標準の `Cmd+Shift+4` とは別の機能です。

| 操作 | 結果 |
|------|------|
| ドラッグ | 任意の範囲 |
| クリック | カーソル下のウィンドウ（ホバー中は枠が光ります） |
| `F` | カーソルのあるモニタ全体 |
| `A` | 全モニタ |
| `Esc` / 右クリック | 中止 |

範囲を決めた時点で、撮ったままの画像がクリップボードに入ります。エディタで手を入れなくても、そのまま `Ctrl+V` で貼れます。
続けて撮ると、前のスクリーンショットのエディタは閉じて新しいものに置き換わります（撮影中は写り込まないよう隠れ、中止すると戻ります）。履歴やクリップボードから開いたエディタはそのまま残ります。

メニューやツールチップのように、キーを押すと閉じてしまうものを写すときは **ディレイ撮影**（`Ctrl+Alt+D`、常駐アイコンの「数秒後にスクリーンショットを撮る」）を使います。
画面上部にカウントダウンが出るので、その間に写したい状態を作ってください。秒数は設定タブで変えられ（既定3秒）、カウントダウン中にもう一度ショートカットを押すと中止します。

選択すると注釈エディタが開きます。エディタは次の場所からも開けます。

- 呼び出し画面で画像の行を選び `Ctrl+E`、または右クリックして「この画像を編集」
- 常駐アイコンの「スクリーンショットを撮る」「クリップボードの画像を編集」
- 設定・編集画面の履歴タブの「画像を編集」

### 注釈エディタの使い方

1. 上段のアイコンからツールを選びます。アイコンにカーソルを合わせると説明が出ます。
2. 色（パレットまたは「…」で任意の色）、太さ、文字サイズ、フォント、塗りつぶしを必要に応じて変えます。
3. 画像の上でドラッグ（またはクリック）して描きます。
4. 下段のボタンで書き出します。

| ツール | 操作 |
|--------|------|
| 選択 | 図形をクリックして選び、ドラッグで移動、`Delete` で削除。文字はダブルクリックで再編集 |
| 矢印 / 矩形 / 楕円 | ドラッグで描く。矩形・楕円は「塗りつぶし」で中を塗れる |
| ペン | ドラッグで自由線 |
| 文字 | クリックした位置に入力欄が開く。`Enter` で改行、`Ctrl+Enter`（macOSでは `Cmd+Enter`）で確定、`Esc` で取りやめ。入力中に文字サイズ・フォント・色を変えるとその場で反映され、既存の文字をダブルクリックで開くとその文字の設定がツールバーに表示される |
| 番号 | クリックするたびに 1、2、3… のバッジを置く |
| マーカー | ドラッグした範囲を半透明で塗る |
| ぼかし / モザイク | ドラッグした範囲の見た目を崩す |
| 切り抜き | ドラッグした範囲だけを残す。「切り抜き解除」でいつでも戻せる |

「フォント」には、この端末に入っている日本語が描けるフォントが並びます（PILは1文字ずつの代替ができないため、日本語を持たないフォントは出しません）。一覧は初回起動時にバックグラウンドで数秒かけて集め、`fonts.json` に記憶します。選んだフォントは既定として保存され、次回のエディタでもそのまま使われます。「選択」ツールで文字を選んでからフォントを変えると、その文字だけが変わります。

| キー | 動作 |
|------|------|
| `Ctrl+Z` / `Ctrl+Y` | 取り消し / やり直し |
| `Ctrl+C` | クリップボードへコピー（文字の入力中は入力欄の文字をコピー） |
| `Ctrl+S` | 名前を付けて保存 |
| `Delete` / `BackSpace` | 選択中の図形を削除 |
| `Ctrl+ホイール`、`Ctrl++` / `Ctrl+-` | 拡大縮小。`Ctrl+0` で全体表示、`Ctrl+1` で100% |
| `Esc` | 文字入力の取りやめ → 選択解除 → エディタを閉じる、の順に働く |

macOSでは上記の `Ctrl` を `Cmd` に読み替えてください（`Ctrl` のままでも動きます）。

書き出しは4通りです。

- クリップボードへコピー: そのまま他のアプリへ `Ctrl+V` で貼れます。設定で「コピーした編集結果を履歴へ残す」がオンなら履歴にも入ります
- 名前を付けて保存: PNG / JPEG で保存します。既定の保存先と形式は設定タブで変えられ、「保存後にクリップボードへもコピー」もあります
- 履歴へ保存: 元の画像とは別の項目として履歴に追加します
- ⇱ ドラッグして渡す: このラベルを他のアプリ（チャット、メール、エクスプローラーなど）へドラッグ＆ドロップするとPNGファイルとして渡ります

**秘匿について**: ぼかしとモザイクは見た目を崩すだけで、元の内容を復元されない保証はありません。また画像の上に置いた文字や図形は
隠せません（ぼかしは下の写真にだけ効きます）。確実に消したいときは「矩形」＋「塗りつぶし」を使ってください。

撮影は両OSでマルチモニタとウィンドウ単位の選択に対応します。Windowsでは混在DPIでの動作を確認しています。macOSではQuartzから
全ディスプレイをまとめて読み取り、Retinaでは実ピクセルのまま切り出します。macOSは「画面収録」の許可がないと撮影できないため、
未許可のときは設定タブを開いて案内します。

## テキスト整形

「整形」タブでルールを追加し、履歴のテキストに適用できます。使い方は3通りです。

- 手動: 「履歴」タブで項目を選び、「整形」タブでルールを選んで「選択履歴へ適用」（またはダブルクリック）
- ショートカット: ルールにショートカットを設定すると、どのアプリからでもクリップボードの内容を整形できます
- 自動: 「コピー時に自動適用」を有効にすると、外部アプリでコピーした直後に変換して履歴へ保存します

| 方法 | 動作 | 値1 | 値2 |
|------|------|-----|-----|
| 各行に挿入 | 各行の先頭に文字列を付ける | 先頭に付ける文字列 | 使わない |
| 各行の前後に挿入 | 各行を文字列で挟む | 前 | 後 |
| 連番 | 各行の先頭に `001: ` のような番号を付ける | 桁数 | 区切り |
| 正規表現置換 | パターンに一致した部分を置換 | 正規表現 | 置換文字列 |
| 前後空白削除 | 全体の前後の空白と改行を削除 | 使わない | 使わない |
| 大文字化 / 小文字化 | 英字を大文字または小文字にする | 使わない | 使わない |
| 全文の前後に挿入 | テキスト全体を文字列で挟む | 前 | 後 |

正規表現の置換文字列では、Python互換の `\1` と、Cliborで使われる `$1` の両方を後方参照として利用できます。
既定で「各行先頭に > を挿入」「各行先頭に // を挿入」「各行を引用符で囲む」「001: の連番を挿入」の4つが登録されています。

## バックアップとCSV

- JSON書き出し: 履歴を含めず、Windows / macOSで共有する設定・定型文・色・画像の一覧を保存（画像ファイル自体は含まない）
- 全バックアップ: 設定、テキスト履歴、画像履歴、登録した画像をZIPへ保存
- 定型文CSV: UTF-8 BOM付きで出力し、UTF-8またはShift_JISを取り込み
- 復元時は、現在のデータを `before-restore.zip` へ自動退避

## 他の端末への引き継ぎ

設定タブの「他の端末への引き継ぎ」で、定型文・色・画像（ファイル込み）・整形ルール・ショートカット・配色を1つのZIPにまとめられます。

1. 端末Aで「引き継ぎパッケージを書き出す」→ `ShinClipboard-settings.zip` を保存
2. ZIPを端末Bへコピーし、「引き継ぎパッケージを取り込む」で選択
3. 取り込み方法を選ぶ

| 取り込み方法 | 動作 |
|--------------|------|
| 追加する | 今ある定型文などは残し、パッケージにしかないものを加える。同じ名前のグループは合流し、同じ内容の項目（定型文は本文、色は値、画像は同じファイル）は二重にならない。何度取り込んでも結果は同じ |
| 置き換える | 定型文・色・画像・整形ルール・ショートカット・配色をパッケージの内容にする。以前の設定は `config.json.bak` に残る |

どちらでも履歴と、スクリーンショットの保存先のような端末固有の設定は変わりません。

設定だけを軽く移したいときは同じ場所の「設定を書き出す／読み込む」（JSON）も使えます。こちらは全置き換えのみで、画像ファイルは含みません。

クラウド同期フォルダの同一ファイルを直接使う場合は、次のように起動できます。

```powershell
python main.py --config "D:\Sync\ShinClipboard\config.json"
```

```bash
python3 main.py --config "$HOME/Sync/ShinClipboard/config.json"
```

## テストと実行ファイル

テストは両OSで同じです。

```bash
python -m unittest discover -v
```

実行ファイルも同じspecからビルドします。ビルドするOSの実行ファイルだけが作られるので、Windows版はWindows上で、macOS版はmacOS上でビルドしてください。

```bash
python -m pip install pyinstaller
python -m PyInstaller --clean ShinClipboard.spec
```

| OS | 生成物 | 形式 |
|----|--------|------|
| Windows | `dist/ShinClipboard.exe` | onefile（単体のexe） |
| macOS | `dist/ShinClipboard.app` | アプリバンドル |

macOSではonefileではなくバンドルにしています。起動が速いのに加えて、アクセシビリティと画面収録の許可はパスに紐づくため、
起動のたびに自己展開する形式では毎回許可を求められてしまうからです。

### macOSの署名

macOSはアクセシビリティと画面収録の許可を**コード署名に対して**記録します。署名なし（ad-hoc）でビルドすると署名がバイナリのハッシュになるため、
ビルドし直すたびに別のアプリ扱いになり、システム設定のトグルはONのままなのに許可が効かなくなります。

そのためspecはビルド時にキーチェーンの署名用証明書を探し、見つかればそれで署名します。Apple Developer の
「Apple Development」証明書があればそのまま使われ、再ビルドしても許可が維持されます。

```bash
security find-identity -v -p codesigning        # 使える証明書の一覧
SHINCLIPBOARD_CODESIGN_IDENTITY="Apple Development: 名前 (TEAMID)" python -m PyInstaller --clean ShinClipboard.spec   # 明示する場合
SHINCLIPBOARD_CODESIGN_IDENTITY=- python -m PyInstaller --clean ShinClipboard.spec   # ad-hoc に戻す場合
```

証明書がないときはad-hoc署名になり、ビルドのたびに許可の付け直し（トグルをOFF→ON）が必要です。
署名の種類を切り替えた直後も一度だけ付け直してください。

配布するときは `.app` をそのままzipせず、シンボリックリンクを保てる `ditto` を使ってください。

```bash
ditto -c -k --keepParent dist/ShinClipboard.app dist/ShinClipboard-mac.zip
```

アプリアイコンのソースは `assets/shinclipboard.png` です。Windows用は `assets/shinclipboard.ico`、macOS用は
`assets/shinclipboard.icns` で、後者は `python tools/make_icns.py` で作り直せます（macOSのアイコングリッドに合わせて余白を入れます）。

## 保存先

- Windows: `%APPDATA%\ShinClipboard\config.json`、`history.json`、`fonts.json`、`images/`、`library/`、`exports/`
- macOS: `~/.shinclipboard/config.json`、`history.json`、`fonts.json`、`images/`、`library/`、`exports/`

`images/` は画像履歴、`library/` は「画像」タブに登録した画像です。履歴から消えた画像は自動で削除されますが、`library/` は登録を消したときにだけ削除します。`exports/` は編集結果をクリップボードやドラッグ＆ドロップで渡すための一時ファイル置き場です。起動時と終了時に古いものを削除します。`fonts.json` は注釈エディタのフォント一覧のキャッシュで、フォントフォルダに変化があれば作り直されます。消しても次回起動時に作り直すだけです。

設定JSONはスキーマバージョン付きです。読み込み時は現設定を `config.json.bak` に退避してから置換します。

## 配布版の実行について

### Windows

`ShinClipboard.exe` は単体で動きます。Pythonのインストールもインストーラーも管理者権限も不要で、任意の場所に置いてダブルクリックするだけです。Python本体・Tcl/Tk・VC++ランタイムはすべてexeに同梱されています。

ただし現在このexeはコード署名していないため、ダウンロード後の初回起動時にWindows SmartScreenの警告（「Windows によって PC が保護されました」）が表示されます。起動するには次の操作が必要です。

1. 警告画面の「詳細情報」をクリックする
2. 表示された「実行」ボタンをクリックする

同じ理由で、ウイルス対策ソフトが誤検知することがあります。PyInstallerのonefile形式は起動時に一時フォルダへ自己展開するため、この挙動が検知対象になりやすいためです。

アンインストールはexeを削除するだけです。設定と履歴は上記の「保存先」に残るので、必要なら合わせて削除してください。

### macOS

`ShinClipboard.app` も単体で動きます。Pythonのインストールは不要で、Python本体とTcl/Tkはバンドルに同梱されています。
「アプリケーション」フォルダへドラッグしてください。

起動するとDockではなくメニューバーに常駐します。ウィンドウを閉じても終了はせず、メニューバーアイコンの「終了」で終わります。

配布版はDeveloper IDでの署名と公証をしていないため、ダウンロードした `.app` はGatekeeperに止められます（開発用の証明書で署名していても同じです）。初回だけ次の操作が必要です。

1. `.app` を右クリック（またはControlキーを押しながらクリック）して「開く」を選ぶ
2. 確認ダイアログの「開く」をクリックする

`"ShinClipboard"は壊れているため開けません` と出るときは、ダウンロード時に付いた検疫属性を外してください。

```bash
xattr -dr com.apple.quarantine /Applications/ShinClipboard.app
```

初回起動時にアクセシビリティと画面収録の許可を求めます。詳しくは「macOSの許可」を参照してください。
証明書なし（ad-hoc署名）でビルドしたものは、ビルドし直すと別のアプリ扱いになり、システム設定のトグルがONのままでも許可が効かなくなります。
その場合はトグルをOFF→ONにしてアプリを再起動してください。証明書で署名すれば再ビルドしても維持されます（「macOSの署名」を参照）。

アンインストールは `.app` を削除するだけです。設定と履歴は上記の「保存先」に、自動起動の登録は
`~/Library/LaunchAgents/com.shinclipboard.app.plist` に残るので、必要なら合わせて削除してください。

## NewClipboardからの移行

0.3.0でアプリ名を NewClipboard から ShinClipboard へ変更しました。旧名称で使っていた場合、初回起動時に次を自動で引き継ぎます。

- 保存データ（`%APPDATA%\NewClipboard` / `~/.newclipboard`）を新しい保存先へ**コピー**します。旧フォルダはそのまま残すので、動作を確認してから手動で削除してください
- OSの自動起動登録を新しい実行ファイルへ付け替え、旧登録を削除します

旧バージョンで作成したZIPバックアップとCSVは、そのまま読み込めます。
